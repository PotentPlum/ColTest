Searching and adding cards now work the way you'd expect, and you can fix a copy's details without removing it.

## Fixed
- **Search works properly.** Letters no longer go missing while you type, and the results stay visible above the keyboard. The header, counter and tabs fold away while you type, and the whole search box responds to a tap.
- **Tapping a card no longer adds it straight away.** It opens the card panel with a larger image (tap it to zoom). Nothing is added until you press an add button. Undo works as before.

## Improved
- **Edit a copy in place**: on a Pokémon's page or in Add Card, tap a line of copies to change its variant, condition or language. If it then matches another line, the two merge and the quantities add up.
- **Plain words instead of codes**: conditions show as Mint, Near Mint, Excellent… and languages as English, German, Polish… ("PL" used to mean both Played and Polish).
- **The add button says what you're adding**, e.g. "ADD · NEAR MINT · ENGLISH", because condition and language carry over from your last add.
- **More room for the grid**: the National Dex counter folds away while you scroll. The first generation tab is now called **National**, so it isn't confused with the All / Missing / Caught filter.
- **Scrolling the results closes the keyboard**, on the main grid and in Add Card.

## Install
Download `pokedex-tracker-v1.2.0.apk` below and open it on an Android 8.0+ phone.

**Updating from v1.1.0:** this build is signed with a different temporary key, so Android will probably refuse to install it over v1.1.0. To keep your collection:
1. In v1.1.0, open ⋮ → **Back up collection** and save the file.
2. Uninstall v1.1.0, then install v1.2.0.
3. Open ⋮ → **Restore from backup** and pick the file.

Uses the free, keyless [PokeAPI](https://pokeapi.co) and [Pokémon TCG API](https://pokemontcg.io).
